Установка

1

Fabric Loader

Поставь Fabric Installer для Minecraft 1.20.1. Запусти установщик, выбери версию и нажми Install.

2

Fabric API

Скачай Fabric API для 1.20.1 и положи fabric-api-*.jar в папку mods.

3

WORKUP

Нажми кнопку «Скачать .jar» выше. Файл workup-v1.6.0.jar кинь в ту же папку mods.

4

Запуск

Выбери в лаунчере профиль fabric-loader-1.20.1 и запусти игру. Меню клиента — клавиша R.

⚠ Папка mods открывается так: в лаунчере → Настройки профиля → «Игровая директория», либо %appdata%\.minecraft\mods. Не клади два jar'а WORKUP сразу — оставь только один.
