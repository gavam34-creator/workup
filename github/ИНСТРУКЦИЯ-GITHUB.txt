КАК ВЫЛОЖИТЬ САЙТ НАВСЕГДА ЧЕРЕЗ GITHUB (бесплатно, ~4 минуты)
GitHub работает в РФ без VPN — проверено.
===============================================================

ПОДГОТОВКА: в папке github лежат два файла —
  index.html  (сам сайт)
  workup-v1.4.jar  (мод, кнопка скачивания уже на него ссылается)

ШАГ 1 — аккаунт
  Открой https://github.com/signup
  Зарегистрируйся (почта + пароль + ник).

ШАГ 2 — репозиторий
  Нажми "+" в правом верхнем углу → "New repository"
  Repository name: например  workup-mod
  Выбери Public  →  нажми "Create repository"

ШАГ 3 — загрузи файлы
  На странице репозитория нажми "uploading an existing file"
  (или "Add file" → "Upload files")
  Перетащи ОБА файла из папки github (index.html и workup-v1.4.jar)
  Нажми "Commit changes"

ШАГ 4 — включи сайт
  В репозитории: Settings → слева "Pages"
  В блоке "Build and deployment":
    Source: Deploy from a branch
    Branch: main, папка: / (root)  →  Save
  Подожди 1-2 минуты, обнови страницу — сверху появится зелёная
  плашка с адресом вида:

  https://ТВОЙНИК.github.io/workup-mod/

  ЭТО И ЕСТЬ ССЫЛКА ДЛЯ ДРУЗЕЙ. Скачивание кнопкой работает само.

===============================================================
ОБНОВЛЕНИЕ МОДА: замени workup-v1.4.jar в репозитории на новый
(Add file → Upload files → перезапиши) — сайт обновится сам.
