КАК ВЫЛОЖИТЬ САЙТ НАВСЕГДА (бесплатно, 2 минуты)
=================================================

Вариант 1 — Netlify Drop (самый простой)
1. Открой https://app.netlify.com/drop
2. Зарегистрируйся (можно через Google)
3. Перетащи ПАПКУ site целиком в окно
4. Получишь ссылку вида https://имя.netlify.app — она вечная
5. Файл workup-v1.6.0.jar уже внутри — скачивание будет работать

Вариант 2 — GitHub Pages
1. Создай аккаунт на https://github.com
2. Создай репозиторий (кнопка New), имя любое, Public
3. Upload files → перетащи index.html и workup-v1.6.0.jar → Commit
4. Settings → Pages → Source: main branch, Save
5. Через минуту сайт: https://твойник.github.io/имя-репозитория

Вариант 3 — tiiny.host
1. Открой https://tiiny.host
2. Загрузите site.zip (лежит рядом с этой папкой)
3. Имя сайта → Register → готово

ВАЖНО: при обновлении мода просто замени workup-v1.6.0.jar
в хостинге на новый (имя файла не меняй).
